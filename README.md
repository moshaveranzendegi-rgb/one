# RS ai — استودیوی محلی ساخت ویدئوی آواتار

هدف پروژه: ساخت کلیپ ۳۰ تا ۱۸۰ ثانیه با عکس آواتار، عکس محیط، سناریو و صدا. رابط فارسی، ورودی صدای کاربر یا TTS، زیرنویس، اندازه‌های شبکه‌های اجتماعی، مسیر خروجی و تعویض لباس چندبخشی را در بر می‌گیرد.

## وضعیت صادقانه
سورس برنامه، کلاینت Android و گردش‌کار ساخت در مخزن هستند. بستهٔ ویندوز و APK در GitHub Actions ساخته می‌شوند؛ فایل‌های حجیم مدل هوش مصنوعی داخل ZIP برنامه نیستند. موتور اصلی OmniAvatar بر پایهٔ Wan2.1 1.3B و Wav2Vec است و باید روی دستگاه کاربر با WSL2 و GPU سازگار NVIDIA نصب شود. وجود سورس یا گذر آزمون‌های نرم‌افزار به‌تنهایی تضمین تولید ویدئوی واقعی نیست.

## نصب Windows
1. `RS-ai-Complete-Source.zip` را خارج کن.
2. `INSTALL_RS-ai.bat` را اجرا کن. به Python 3.11+ و اینترنت نیاز دارد.
3. FFmpeg را نصب کن؛ اگر در `C:\ffmpeg\bin\ffmpeg.exe` باشد، برنامه آن را خودکار پیدا می‌کند.
4. برای نصب موتور اصلی، `%LOCALAPPDATA%\Programs\RS-ai\tools\setup_avatar_wsl.bat` را اجرا کن. این اسکریپت ابتدا دسترسی GPU در WSL و سپس فایل‌های مدل را بررسی می‌کند و از دانلود بی‌دلیل وزن‌ها در صورت نبود GPU جلوگیری می‌کند.
5. بعد از اتمام، RS ai را باز کن و «وضعیت موتور‌ها» را بررسی کن.

پیش‌نیازهای موتور اصلی: توزیع Ubuntu در WSL2، درایور NVIDIA سازگار با WSL، دسترسی CUDA از داخل WSL و حدود 20 تا 30GB فضای آزاد. در PowerShell:
```powershell
nvidia-smi
wsl --list --verbose
```
اگر Ubuntu نصب نیست، PowerShell را با Administrator باز کن و `wsl --install -d Ubuntu` را اجرا کن.

مدل‌ها و پیکربندی بر اساس مستندات رسمی‌اند:
- [OmniAvatar](https://github.com/Omni-Avatar/OmniAvatar)
- [Wan2.1-T2V-1.3B](https://huggingface.co/Wan-AI/Wan2.1-T2V-1.3B)
- [OmniAvatar-1.3B](https://huggingface.co/OmniAvatar/OmniAvatar-1.3B)
- [Wav2Vec2](https://huggingface.co/facebook/wav2vec2-base-960h)

## Android
`android/` شامل سورس Android Studio است. اپ WebView به پنل RS ai روی رایانه متصل می‌شود؛ مدل سنگین روی خود گوشی اجرا نمی‌شود. APK در صفحهٔ Release ساخته می‌شود، اما نصب/اتصال روی گوشی واقعی باید در محیط کاربر آزمایش شود.

## قابلیت‌ها و محدودیت‌ها
- زبان‌های رابط/صدا: فارسی، انگلیسی و روسی؛ کیفیت همگام‌سازی لب در مدل اصلی برای فارسی هنوز نیازمند تست واقعی است.
- صدای متنی Edge TTS به اینترنت نیاز دارد؛ فایل صوتی کاربر هم قابل انتخاب است.
- زیرنویس صدای آپلودی به نصب faster-whisper نیاز دارد.
- عکس محیط نیازمند حذف پس‌زمینه است.
- تعویض لباس نیازمند نصب وزن‌های FASHN VTON است.
- تکمیل بدن از عکس نیم‌تنه نیازمند مدل inpainting جداگانه است.
- انتشار و زمان‌بندی پست شبکه‌های اجتماعی در این نسخه فعال نیست.

## آزمون و بسته‌بندی
در Python 3.11:
```bat
python -m pip install -r requirements.txt httpx
python -m compileall -q app tools tests
python -m unittest discover -s tests -v
```
هر فایل دانلودی/پارت باید کمتر از 200MB باشد. برای اتصال پارت‌ها، فایل‌های هم‌نام `.part001`, `.part002`, ... و فایل `.sha256.txt` را کنار هم قرار بده و از `JOIN_PARTS.bat` استفاده کن.

## بدون GPU NVIDIA روی رایانهٔ محلی
اگر سیستم فقط گرافیک Intel دارد، موتور OmniAvatar را محلی نصب نکن. راهنمای ابری و دفترچهٔ آزمایشی Colab را در `CLOUD_GPU_GUIDE_FA.md` و `notebooks/RS-ai-OmniAvatar-Colab.ipynb` ببین. دفترچه ابتدا یک کلیپ ۵ ثانیه‌ای را آزمایش می‌کند؛ اجرای کامل روی GPU رایگان تضمین‌شده نیست و اتصال خودکار برنامه به نشست ابری هنوز فعال نشده است.
