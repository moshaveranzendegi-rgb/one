# RS ai — استودیوی محلی ساخت ویدئوی آواتار

هدف پروژه: ساخت کلیپ ۳۰ تا ۱۸۰ ثانیه با عکس آواتار، عکس محیط، سناریو و صدا. رابط فارسی، ورودی صدای کاربر یا TTS، زیرنویس، اندازه‌های شبکه‌های اجتماعی، مسیر خروجی و تعویض لباس چندبخشی را در بر می‌گیرد.

## وضعیت صادقانه
این مخزن سورس برنامه و گردش‌کار ساخت است. فایل‌های بزرگ OmniAvatar را در بر ندارد؛ تولید آواتار واقعی به WSL2، GPU سازگار NVIDIA و وزن مدل‌های جداگانه نیاز دارد. ساخت EXE ویندوز و APK باید در GitHub Actions تأیید شود؛ تست سورس به‌تنهایی به معنای تأیید اجرا روی دستگاه واقعی نیست. در نبود موتور اصلی، برنامه از تحویل عکس ثابت با صدا به‌عنوان ویدئوی متحرک خودداری می‌کند.

## نصب Windows
1. Python 3.11+ و FFmpeg را نصب کن.
2. `INSTALL_RS-ai.bat` را اجرا کن.
3. `RUN_RS-ai.bat` رابط محلی را باز می‌کند.
4. برای موتور متحرک، WSL2/Ubuntu، GPU NVIDIA و مدل‌های OmniAvatar لازم است؛ `tools/setup_avatar_wsl.bat` راه‌انداز نصب است.

## Android
`android/` شامل سورس Android Studio است، نه APK از پیش ساخته‌شده. اپ WebView به پنل روی رایانه متصل می‌شود؛ مدل سنگین روی میزبان اجرا می‌شود. برای ساخت APK، JDK 17، Android SDK Platform 35 و Gradle 8.9 لازم است.

## قابلیت‌ها و محدودیت‌ها
- زبان‌ها: فارسی، انگلیسی و روسی.
- صدای متنی با Edge TTS به اینترنت نیاز دارد؛ فایل صوتی خود کاربر هم قابل انتخاب است.
- زیرنویس صدای آپلودی نیازمند Whisper است.
- عکس محیط نیازمند حذف پس‌زمینه است.
- تعویض لباس نیازمند نصب وزن FASHN VTON است.
- انتشار و زمان‌بندی پست شبکه‌های اجتماعی هنوز در این نسخه فعال نیست؛ به مجوز و API رسمی هر سرویس نیاز دارد.

## ساخت/آزمون
در Python 3.11:
```bat
python -m pip install -r requirements.txt httpx
python -m compileall -q app tools tests
python -m unittest discover -s tests -v
```

- ساخت Windows: `BUILD_EXE_WINDOWS.bat`
- بسته‌بندی Windows: `PACKAGE_EXE_WINDOWS.bat`
- ساخت APK: `android/BUILD_APK_WINDOWS.bat`
- پیوستن پارت‌ها: `JOIN_PARTS.bat`

تمام فایل‌های دانلودیِ تقسیم‌شده باید کمتر از ۲۰۰٬۰۰۰٬۰۰۰ بایت باشند و با SHA-256 اعتبارسنجی شوند.
