# برنامهٔ اجرایی RS ai

## هسته و رابط
- فرم فارسی راست‌چین، تنظیمات، اعتبارسنجی ورودی و API توکن‌دار.
- صف پروژه‌ها و ثبت وضعیت/خطا در SQLite.

## رسانه
- TTS برای متن یا ورودی صدای کاربر.
- زیرنویس زمان‌دار و نرمال‌سازی صدا.
- انتخاب ابعاد و فرمت با اعتبارسنجی صدا و تصویر خروجی.

## هوش مصنوعی
- OmniAvatar 1.3B برای ویدئوی آواتار متحرک.
- FASHN VTON برای لباس‌های متداول.
- inpainting اختیاری برای تکمیل بدن ناقص.
- حذف پس‌زمینه برای ترکیب عکس محیط.
- در صورت شکست موتور، هیچ خروجی عکس ثابت به جای آواتار متحرک صادر نمی‌شود.

## کلاینت‌ها و انتشار
- ساخت Windows portable EXE روی GitHub Actions.
- ساخت APK دیباگ Android و اتصال به رایانهٔ میزبان در شبکهٔ محلی.
- پیش از توزیع: تست واقعی در Windows، Android و GPU/WSL2.

## ادعاهایی که نباید به‌عنوان تکمیل‌شده معرفی شوند
- تولید آواتار روی سخت‌افزار کاربر.
- EXE/APK تأییدشده روی دستگاه واقعی.
- انتشار مستقیم و زمان‌بندی شبکه‌های اجتماعی.
