# شهر آینه | Shahr-e Ayeneh

پروژهٔ بازی معمایی و روایی فارسی، راست‌به‌چپ و آفلاین.

این پوشه در مخزن متصل، مسیر کاری مستقلی برای پروژه است. ساخت مخزن تازه از طریق ابزارهای GitHub این اتصال در دسترس نیست؛ بنابراین کار در شاخهٔ project/shahr-e-ayeneh و پوشهٔ projects/shahr-e-ayeneh ثبت شده تا به شاخهٔ اصلی دست نخورد.

## فایل‌ها
- index.html: پروتوتایپ سبک و قابل اجرا با شش شهر، فهرست ۱۷۴ مرحله، سرنخ، دفترچه و ذخیرهٔ محلی.
- docs/TEAM_COUNCIL.md: ۲۶ نقش تخصصی برای نقد چندرشته‌ای شبیه‌سازی‌شده.
- docs/IDEAS_78.md: ۷۸ پیشنهاد با اولویت و تلاش تقریبی.
- docs/SCENE_BIBLE.md: طراحی صحنهٔ شش شهر.
- docs/CONFLICT_MAPPING.md: نگاشت تعارض‌ها به مناطق.
- docs/ARCHITECTURE_ROADMAP.md: معماری و فازهای اجرا.
- docs/QA_CHECKLIST.md: معیارهای آزمون.
- docs/DECISION_LOG.md: تصمیم‌ها و ریسک‌ها.
- assets/cities/*.svg: تصاویر برداری مستقل شش شهر.
- data/city-conflict-mapping.json: نگاشت ماشین‌خوان.
- data/stage-template.json: قرارداد مرحلهٔ نمونه.

## اجرا
فایل index.html را باز کن. تصاویر کنار آن هستند و آفلاین بارگذاری می‌شوند. فهرست مراحل و دفترچه از صفحه قابل دسترسی‌اند.

## وضعیت صادقانه
این پوشه شامل پروتوتایپ آغاز توسعه است، نه ادعای تکمیل همهٔ امکانات نهایی. انتقال فایل HTML بزرگِ نسخهٔ قبلی به GitHub از طریق اتصال فعلی امکان مستقیم نداشت؛ نسخهٔ کامل پیشین در بستهٔ دانلودی گفتگو موجود است. نویسندگی اختصاصی و بازی‌آزمایی ۱۷۴ مرحله همچنان لازم است.
