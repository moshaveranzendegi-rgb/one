# چک‌لیست QA
- [ ] بازی بدون دادهٔ قبلی شروع شود.
- [ ] ذخیرهٔ معتبر بارگذاری و ذخیرهٔ خراب به‌صورت امن مدیریت شود.
- [ ] خروجی و بازیابی پیشرفت آزمایش شود.
- [ ] بازی جدید، پیشرفت قبلی را ناخواسته پاک نکند.
- [ ] جهت‌نما، WASD، فاصله و کنترل لمسی کار کنند.
- [ ] همهٔ پنل‌ها با صفحه‌کلید قابل پیمایش باشند.
- [ ] هر مرحله شناسهٔ یکتا، شهر و تعارض معتبر داشته باشد.
- [ ] سرنخ فقط یک‌بار پاداش اصلی بدهد.
- [ ] پاسخ غلط بازخورد و امکان ادامه داشته باشد.
- [ ] پاسخ درست مرحلهٔ بعد را باز کند.
- [ ] تصویر، نام، اشیا و سؤال با هم هماهنگ باشند.
- [ ] پاسخ با شواهد قابل استنتاج باشد.
- [ ] متن، بازیکن را تشخیص یا برچسب روانی ندهد.
- [ ] کنتراست و کاهش حرکت رعایت شوند.
- [ ] یک مرورگر دسکتاپ و یک دستگاه موبایل آزمایش شوند.
- [ ] پیش از تغییر بزرگ نسخهٔ پشتیبان تهیه شود.
